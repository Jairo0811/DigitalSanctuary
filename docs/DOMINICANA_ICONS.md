# Dominicana Icons — Visual Identity Patch

Este patch incorpora iconografía dominicana como identidad visual contextual en Digital Sanctuary.

## Implementación

- `app/src/main/res/drawable/mapa_rd.xml`: adaptación Android Vector Drawable del icono `mapa-rd` suministrado para el proyecto.
- `SettingsScreen`: marcador discreto de República Dominicana al final de la configuración.

## Criterios

- La iconografía dominicana es decorativa/contextual; no sustituye iconos de navegación, lectura, notas, ajustes ni acciones.
- El texto conserva el significado cuando el recurso gráfico no está disponible para tecnologías de asistencia.
- El marcador respeta el enfoque de alto contraste y baja complejidad visual de Digital Sanctuary y pantallas E-ink.
- No introduce cambios en almacenamiento, lector, IA, base de datos ni lógica de configuración.

## Procedencia

El recurso visual parte del paquete `dominicana-icons` suministrado para esta integración. Este documento no añade ni modifica términos de licencia del recurso original.
